Editor Hotkeys

These shortcuts work while you are typing in the Inputs box of the diagram builder. Each one acts on the line the cursor is on, or on every line touched by the current selection.

KeysWhat it does
Ctrl + /Comment out the line(s) with //, or uncomment them if they are already comments.
Alt + ↑ / ↓Move the line(s) up or down.
Alt + Shift + ↑ / ↓Duplicate the line(s) above or below.
Ctrl + Shift + KDelete the line(s).
Ctrl + CWith nothing selected: copy the whole current line.
Ctrl + XWith nothing selected: cut the whole current line.

Good to know

  • Ctrl or Cmd: On a Mac, Cmd works anywhere Ctrl is listed, and Alt is the Option key.
  • Undo: Every shortcut can be reversed in one step with Ctrl + Z.
  • Copy & cut: When you have text selected, Ctrl + C and Ctrl + X behave exactly as they normally do.
  • Comments: Lines starting with ' also count as comments, so uncommenting removes either marker.
